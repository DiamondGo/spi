## sPi 0.1.5 — 会话恢复与桌面交互 / Session recovery and desktop controls

### 新功能

- **按需 RPC 健康检查与恢复**：正常空闲不轮询；发送失败或被过期忙碌状态阻塞时检查。异常退出保留标签页，支持恢复原历史、草稿和暂停的待发送队列，不自动重发未确认消息。
- **终端显示切换**：再次点击终端按钮即可隐藏，再点恢复原 PTY；shell、后台任务和输出不丢失。
- **终端右键菜单**：复制、粘贴、全选、清屏、隐藏和关闭，保留原有快捷键与终端控制序列安全边界。
- **会话名称**：列表与标签页可双击或右键手动重命名；也可使用该会话当前模型生成建议，预览/编辑后保存，不执行工具、不写入聊天。
- **会话管理菜单**：右键提供重命名、AI 命名和确认后删除。历史移入系统回收站，不删除项目文件；删除失败时不降级为永久删除。
- **窗口状态记忆**：恢复上次位置、尺寸和最大化状态；显示器变化时将窗口调整回可见区域。

### Changes

- Passive, single-flight health diagnostics and explicit session recovery; no idle/focus/network-restoration polling, automatic restart or blind replay of work.
- Toggle terminal visibility without restarting the shell; Copy/Paste/Select all/Clear/Hide/Close context menu.
- Consistent manual/AI session names across directory/recent lists and tabs. AI naming uses the selected session's model, requests no tools, and requires confirmation before saving.
- Confirmed history deletion through the system trash; project files remain untouched.
- Persistent normal window bounds and maximized state, with removed-display recovery.
- Native/extracted-runtime release checks now cover the new interactions and retain existing Node-path, workspace, installer, sandbox and PTY checks.

### Install / Update

**桌面 Release 与 npm `spi-agent-gui@0.1.5` 均已公开，npm latest 为 0.1.5。**

**The desktop Release and npm `spi-agent-gui@0.1.5` are public; npm latest is 0.1.5.**

```bash
pi install npm:spi-agent-gui@0.1.5
spi
```

已有安装也可通过 `spi update` 获取最新稳定桌面版本，或下载本 Release 的校验制品。 / Existing installations can alternatively use `spi update` for the latest stable desktop or download the verified assets below.

请先保存重要草稿并完全退出旧窗口，再重新打开；安装不会热更新已运行的 sPi。Pi 认证、已保存会话和 sPi 偏好设置保留。恢复会话不会自动重新执行上一条请求；请核对已产生的工具效果。AI 命名会产生一次正常的模型请求。

Save important drafts and fully quit the previous sPi window before reopening. Installation does not hot-update a running window. Pi authentication, saved history and sPi preferences are preserved. Recovery does not replay a previous request; check existing tool effects before retrying. AI naming incurs a normal model request.

**Public desktop targets: Linux x64 and Linux arm64 only.** A graphical desktop, the published glibc baseline, Electron system libraries and a working Chromium sandbox are required. macOS candidates remain separate; Windows/macOS public support is not added by this release. Older immutable releases are unchanged.

See [session recovery](https://github.com/DiamondGo/spi/blob/main/docs/session-recovery.md) and [desktop controls](https://github.com/DiamondGo/spi/blob/main/docs/desktop-interactions.md) for behavior and limits.
