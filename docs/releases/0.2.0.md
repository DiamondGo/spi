## sPi 0.2.0 — 远程访问 / Remote access

### 新功能

- **远程访问**：在另一台电脑上打开一个 sPi 窗口，直接操作这台电脑上的 sPi。远程窗口与本地窗口功能相同：会话、提示词、工具输出、终端和设置都在 host 上执行。两台电脑可以都在 NAT 或防火墙后面，流量经 Microsoft Dev Tunnels 中继，并由 sPi 两端用 Noise 协议端到端加密，中继只转发密文。
- **一次性配对码**：host 上点"添加设备…"生成配对码（10 分钟内有效，只能用一次），在 client 上粘贴即可配对。双方公钥在配对时固定，之后中继无法冒充任何一方。host 可以随时撤销设备。
- **断线自动重连**：网络中断或 host 暂时关闭远程访问时，远程窗口显示提示，期间的操作直接失败、不会补发；连上后自动刷新会话和终端。host 的隧道过期或被删除时会自动新建，client 自动找回，不需要重新配对。

### 修复

- **AI 命名**：兼容不接受 `reasoning: none` 的推理模型；失败时只显示分类后的错误，不转发服务端原文。
- **会话健康提示**：正常会话不再显示连接横幅；新的 Pi 事件会清除过期的"未响应"状态；模型错误与连接错误分开显示，且只显示一次。

### Changes

- **Remote access (new):** open a window on one sPi desktop that drives another sPi host behind NAT/firewalls, relayed through Microsoft Dev Tunnels and end-to-end encrypted by sPi (Noise XXpsk3 for pairing, IK for resume). One-time pairing codes, pinned keys, device revocation, automatic reconnect with resync, and automatic tunnel recreation/rediscovery.
- AI naming now works on reasoning models that reject `reasoning: none`; failures surface allowlisted categories only.
- Healthy sessions no longer show the connection banner; stale unresponsive state clears on real Pi progress; model errors are shown once and separately from connection errors.
- Release checks now include the remote access unit suite, a two-instance loopback GUI smoke on both native Linux runners, and a packaged-runtime check that the real relay loads and the dev-only relay override is ignored.

### 远程访问的前提与限制 / Remote access requirements and limits

- **两台电脑都要安装 GitHub CLI（`gh`），并登录同一个 GitHub 账号。** sPi 按需读取 `gh auth token`，只保存在内存里，只发给 Dev Tunnels 服务。不用远程访问时不需要 `gh`，也不会连接 GitHub 或 Dev Tunnels。
- **Both computers need the GitHub CLI (`gh`) signed in to the same GitHub account.** Local use never needs `gh`, GitHub or Dev Tunnels.
- **已配对的设备拥有 host 上 sPi 的全部权限，包括终端和 YOLO。** 配对码相当于临时密码，不要发到公开的地方；不用的设备请在 host 上撤销。
- **A paired device has full control of the host's sPi, including terminals and YOLO.** Treat pairing codes like passwords and revoke unused devices.
- Linux 需要可用的系统密钥环来保护设备密钥；没有密钥环时远程访问不可开启，设置里会说明原因。
- Dev Tunnels 仍是公开预览服务；它接受 `gh` 的 token 没有官方文档承诺，随时可能变化。
- 已在 Linux 上通过单元测试、回环中继的双实例 GUI 测试和真实 Dev Tunnels 服务实测。macOS 和 Windows 未验证。

详见 [远程访问与 gh 依赖](https://github.com/DiamondGo/spi/blob/main/docs/remote-access.md)。See [remote access](https://github.com/DiamondGo/spi/blob/main/docs/remote-access.md) for setup, privacy boundaries and failure behavior.

### Install / Update

```bash
pi install npm:spi-agent-gui@0.2.0
spi
```

请先保存重要草稿并完全退出旧窗口，再重新打开；安装不会热更新已运行的 sPi。Pi 认证、已保存会话和 sPi 偏好设置保留。

Save important drafts and fully quit the previous sPi window before reopening. Installation does not hot-update a running window. Pi authentication, saved history and sPi preferences are preserved.

**Public desktop targets: Linux x64 and Linux arm64 only.** A graphical desktop, the published glibc baseline, Electron system libraries and a working Chromium sandbox are required. This release adds no Windows or macOS downloads. Older immutable releases are unchanged.
