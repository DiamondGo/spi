# sPi 0.2.1

## 配对码有效期 / Pairing code lifetime

- 设置 → 远程访问中，生成配对码前可选择有效期：默认 **1 小时**，按整数小时配置，最长 **60 天（1440 小时）**。主进程独立校验期限，不信任界面输入。
- Settings → Remote access lets you choose a pairing code lifetime before generation: **1 hour by default**, configurable in whole hours up to **60 days (1440 hours)**. The host validates the requested lifetime independently.
- 配对码仍然只能使用一次，连续 3 次握手失败作废，并可手动取消。关闭远程访问、退出/重启 sPi 或生成新码会使旧码失效。此期限不限制已经配对的设备。
- Codes remain single-use, are invalidated after three failed handshakes, and can be cancelled. Disabling remote access, quitting/restarting sPi or generating another code invalidates the old code. Paired devices do not expire with the code.
- 两台电脑仍须在 GitHub CLI 登录同一账号；长有效期意味着更长的泄露风险窗口。

## macOS

- 修复 0.2.0 Mac 打包失败：对 Dev Tunnels 引入的 bufferutil / utf-8-validate 原生模块，在签名前清理未使用的预编译包及本地调试路径，保留运行时 JS 入口。
- Fix Mac packaging of the Dev Tunnels native dependencies: remove unused prebuilds and strip local debug paths before signing, preserving runtime JavaScript entry points.
- Public manual ZIP downloads for [Apple Silicon](https://github.com/DiamondGo/spi/releases/download/v0.2.1/spi-0.2.1-darwin-arm64.zip) and [Intel](https://github.com/DiamondGo/spi/releases/download/v0.2.1/spi-0.2.1-darwin-x64.zip), with both native builds and installed-ZIP tests passed. **Ad-hoc signed, NOT Developer ID signed or notarized.** Do not disable OS protections.
- Mac downloads remain supplemental; the canonical automatic installer targets Linux x64/arm64. Existing 0.2.0 assets and npm versions remain unchanged.
