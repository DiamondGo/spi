# sPi 0.3.1

## Context 用量与压缩 / Context usage and compaction

- **Thinking 右侧新增 context 圆环与百分比。** 悬停显示完整 `context used / context max` tokens，读取 Pi 的当前 `contextUsage`，不使用会话累计 token 或费用统计。数值属于 Pi 的估算。
- **左键点击直接压缩**，使用 Pi 原生 `compact` RPC，等价于 `/compact`，不会作为普通聊天消息发送。
- **右键 → 输入压缩指令…**：输入可选 instruction，确认后等价于 `/compact [instruction]`；留空使用默认压缩，取消不发起请求。多行内容按数据字段传递，不作为其他命令执行。
- **压缩后刷新历史与摘要，保留草稿、附件及 outbox。** 相同请求 single-flight；不同 instruction 的并发请求明确拒绝，不默默丢弃指令。错误可见且不自动重试模型请求。
- Pi 在压缩后可能暂时报用量未知，直到下一次有效模型回复；此时显示 `—%`，不伪造为 0%。旧 Pi 无用量字段时也显示未知。
- 会话运行中、存在待执行消息、等待审批或健康状态异常时禁用压缩快捷按钮，避免原生手动 compact 先中断当前任务。压缩期间新的明确发送可以排队，结束后正常处理；已有暂停队列不会被擅自恢复。
- **只读远程端可以查看用量，但不能压缩**；host 的 RPC 白名单强制执行，不依赖禁用界面按钮。

A context ring/percentage now sits to the right of Thinking. Hover for current used/max tokens. Click runs native Pi compaction; right-click opens an optional instruction dialog. The UI preserves drafts/attachments/outbox, refreshes the compacted projection and shows its summary, handles busy/error/unknown usage explicitly, and never sends compaction as an ordinary user prompt. Reading usage does not make model requests; **compaction may incur model costs**.

详见 [context 用量与压缩](../context-usage.md)。

## 更新与平台 / Update and platforms

- Remote protocol remains **v2**, retaining 0.3.0's single-controller/read-only behavior and saved pairings. Update host and client for the complete new context UI/API; 0.2.x/v1 remains incompatible.
- Linux x64/arm64 are canonical automatic installer targets. Mac Apple Silicon/Intel ZIPs remain supplemental **manual downloads**, ad-hoc signed, **not Developer ID signed or notarized**. Do not disable OS protections.
- [Release downloads](https://github.com/DiamondGo/spi/releases/tag/v0.3.1). Existing immutable versions are not replaced.
- Save important drafts, completely quit the old sPi windows and reopen after updating; running windows are not hot-updated. Pi authentication, saved sessions and pairings are preserved.

Install the public npm package:

```bash
pi install npm:spi-agent-gui@0.3.1
# Existing Linux desktop installation:
spi update
```
