# sPi 0.3.3 — minimizable pending messages

## Changes / 更新

- Minimize the pending-message panel with its **−** button into a compact counter at the lower-left of the chat viewport, above Delivery mode / Open terminal. Click or keyboard-activate it to reopen editing.
- Preserve unsaved row text, attachment changes and the editing lease through minimize/restore. Minimizing never pauses delivery or changes the queue revision. The preference is independent per session in the current window; the entry disappears when the queue empties.
- Keep user-question Up/Down and Return to latest clickable with the panel expanded or minimized. Narrow columns and short chat viewports beside an open terminal reserve separate navigation space. Read-only remote windows never expose queue editing controls.
- GitHub remains the primary update channel. This release also targets a matching lightweight npm installer for first installation through `pi install npm:spi-agent-gui`; it downloads the appropriate desktop runtime from GitHub rather than bundling all four platforms in npm.

## Build security note / 构建安全说明

The user explicitly authorized a temporary **0.3.3-only build dependency exception** for [GHSA-fc5q-39xc-vjpf / CVE-2026-112366](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) in picomatch `<=4.0.7`. The upstream issue is **not fixed** by this release. Full audit still reports its inherited high-severity findings; they are not hidden or relabeled.

The policy allows only that exact high advisory/range on lockfile-marked development nodes for version 0.3.3. Other high/critical findings, production paths, incomplete audit data and later versions still fail. Installer bundler inputs reject the build-only dependencies. Each native archive must scan the final ASAR, unpacked/resources scripts and standalone installer for the forbidden modules and picomatch implementation/references, then include a version/content-hash inventory validated again before publication. Inventories are produced by the verified native jobs; they are not an independent publisher-signature guarantee. The exception does not automatically carry forward to later releases and should be removed when an official patched dependency is available.

## Platforms and upgrade / 平台与升级

Supported packages: **Linux x64/arm64, macOS Apple Silicon/Intel**. Windows remains deferred. Mac packages are ad-hoc signed, not Developer ID signed or notarized; no Gatekeeper bypass is supplied.

Existing 0.3.2 desktops can use the GUI update notice or `spi update`. Save unsent drafts before confirming Restart to apply. First-time Pi users can use `pi install npm:spi-agent-gui` once npm latest is verified as 0.3.3; GitHub and npm publication/availability are recorded separately in [verification](https://github.com/DiamondGo/spi/blob/main/docs/verification.md).
