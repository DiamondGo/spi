# sPi 0.3.5 — steer cuts in line, command completion fixed

## Changes / 更新

- **Steer now cuts in line through Pi's native steering queue.** While a run is live, a steer injects the message into that run — delivered after the current turn's tool calls and before the next model call — instead of waiting in the editable outbox for the session to become idle. When idle, a steer starts a run immediately. Normal and follow-up sends keep the editable outbox with its edit/cancel/hold behavior. While an outbox handoff is in flight or outbox work is held (editing/paused), a steer keeps the outbox order at the front instead of racing the in-flight handoff. Stopping the run returns undelivered steering text to the draft via the queue clear.
- `get_state` now reports the native steering/follow-up queues, tracked from Pi `queue_update` events and cleared on exit/recovery/close, so injected steers are observable and the GUI smoke can assert they settled inside the live run.
- **Fix slash-command completion dropping the leading '/'.** Command names from Pi `get_commands` are invocation names without the slash, and applying a selection replaced the trigger character with the bare name, so a selected command was sent as plain text. The draft now keeps the slash-prefixed command; file '@' completion keeps inserting the bare path as before.
- **Retire the 0.3.3/0.3.4 build-only audit exception.** Upstream [withdrew GHSA-fc5q-39xc-vjpf](https://github.com/advisories/GHSA-fc5q-39xc-vjpf) (updated 2026-11-19), and the full `npm audit` now reports **0 high / 0 critical, 8 moderate**. Any high/critical finding blocks again for every version; there is no version allowlist. The build-only module absence checks (picomatch/fdir/tinyglobby/node-gyp/@electron/rebuild) for installer inputs and every final ASAR/unpacked/resources script/standalone helper remain mandatory under the `no-build-dependencies` inventory policy. These native-job inventories are not independent publisher signatures.

插队（steer）现在直接注入正在执行的任务，而不是在可编辑缓冲区里等空闲；普通发送和 follow up 的编辑/取消/暂停行为不变。`/` 命令补全选中后保留前导斜杠，发送即执行 Pi 命令。构建期审计例外随上游撤回通告而移除，产物缺失清单门槛保持。

## Platforms and upgrade / 平台与升级

- Linux x64/arm64 and macOS Apple Silicon/Intel. Mac is ad-hoc signed, **not Developer ID signed or notarized**; no OS protection bypass is provided.
- Existing 0.3.4 installations can use the in-app path: **Settings → Check for updates**, download 0.3.5, save unsent drafts/queue contents, then explicitly confirm **Restart to apply**. `spi update` is the CLI alternative. This publication will not restart the current window for you; installation alone does not hot-update a running app.
- GitHub is the primary desktop update channel; no npm action is needed for that in-app update. The matching lightweight npm package remains the first-install path: `pi install npm:spi-agent-gui@0.3.5` after public npm verification.
- Remote protocol stays v2; saved pairings/profile/history are preserved. Immutable 0.3.4 assets are not replaced.
