# sPi 0.3.6 — directory tree refresh, multi-select session deletion

## Changes / 更新

- **Directory tree refreshes on re-expand.** Collapsing and re-expanding a directory re-scans that level instead of reusing the cached child list, so directories and files created while the folder was collapsed (or while the app was running) appear immediately — no restart or manual refresh needed. First expansion and the initial tree load are unchanged.
- **Ctrl/Cmd+click multi-select session deletion.** Both the current-directory session list and the recent sessions list support multi-select: Ctrl+click (Cmd+click on macOS) toggles rows into a highlighted selection; a plain click still opens the session and clears the selection. With more than one row selected, the right-click menu offers **only “Delete N sessions”** — rename, AI naming, connection check and recovery do not apply to multiple targets. The confirmation dialog lists the selected sessions (first five, then a total) and deletes them one by one: a single failure does not stop the rest, successful deletions stay applied, and failures are reported in the dialog. Stale selections are pruned automatically when rows disappear (e.g. after a successful delete) and cleared when switching directory.

重新展开目录会重新扫描该层内容，折叠期间新建的目录/文件立即出现，无需重启。目录会话列表与最近会话列表支持 Ctrl/Cmd+click 多选；多选时右键只提供「删除 N 个会话」，确认对话框列出所选会话并逐个删除，单个失败不阻断其余并在对话框中报告。

## Platforms and upgrade / 平台与升级

- Linux x64/arm64 and macOS Apple Silicon/Intel. Mac is ad-hoc signed, **not Developer ID signed or notarized**; no OS protection bypass is provided.
- Existing 0.3.5 installations can use the in-app path: **Settings → Check for updates**, download 0.3.6, save unsent drafts/queue contents, then explicitly confirm **Restart to apply**. `spi update` is the CLI alternative. This publication will not restart the current window for you; installation alone does not hot-update a running app.
- GitHub is the primary desktop update channel; no npm action is needed for that in-app update. The matching lightweight npm package remains the first-install path: `pi install npm:spi-agent-gui@0.3.6` after public npm verification.
- Remote protocol stays v2; saved pairings/profile/history are preserved. Immutable 0.3.5 assets are not replaced.
