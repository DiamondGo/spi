# sPi 0.3.7 — editable directory path, right-click copy

## Changes / 更新

- **Editable directory path with jump.** The path title at the top of the directory session list is now editable: click it to open an input pre-filled with the current absolute path, type a directory and press Enter to jump there (`~` and `~/…` expand against the home directory). If the typed path does not exist or is not a directory, an error notice is shown and the list stays on the current directory. Escape or clicking away cancels without jumping.
- **Right-click copy for selected text.** Selecting text with the mouse in the main window (chat area) and right-clicking opens a context menu with a single **Copy** item that copies the exact selection to the clipboard. Without a selection the previous behavior is unchanged, and the terminal keeps its own right-click menu (Copy/Paste/Select all/Clear/Hide/Close).

目录会话列表顶部的路径标题现在可以直接编辑：点击后输入目录并回车即跳转（支持 `~` 展开）；目录不存在时弹出错误提示并留在原目录，Esc 取消。主窗口选中文字后右键可一键复制选区；终端右键菜单不受影响。

## Platforms and upgrade / 平台与升级

- Linux x64/arm64 and macOS Apple Silicon/Intel. Mac is ad-hoc signed, **not Developer ID signed or notarized**; no OS protection bypass is provided.
- Existing 0.3.6 installations can use the in-app path: **Settings → Check for updates**, download 0.3.7, save unsent drafts/queue contents, then explicitly confirm **Restart to apply**. `spi update` is the CLI alternative. This publication will not restart the current window for you; installation alone does not hot-update a running app.
- GitHub is the primary desktop update channel; no npm action is needed for that in-app update. The matching lightweight npm package remains the first-install path: `pi install npm:spi-agent-gui@0.3.7` after public npm verification.
- Remote protocol stays v2; saved pairings/profile/history are preserved. Immutable 0.3.6 assets are not replaced.
