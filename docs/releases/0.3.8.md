# sPi 0.3.8 — /compact routes to the compact RPC

## Changes / 更新

- **`/compact` executes the compact command instead of prompting the model.** In Pi RPC mode a prompt beginning with `/` is not parsed as a built-in command, so typing `/compact` sent the literal text to the model as a plain user message. Sending a draft that is exactly `/compact` (optionally followed by compaction instructions) now calls the session compact RPC — the same path as the title-bar compact control — clearing the draft on success, preserving it with an error notice on failure (for example while the session is busy), and refusing image attachments. Other text containing `/compact` is unchanged, and extension/skill/template commands keep working through the normal prompt path.

输入 `/compact`（可带压缩指令）现在执行上下文压缩，而不是把文本发给模型：RPC 模式下 Pi 不会把 `prompt` 里的 `/compact` 解析为内建命令，sPi 现在直接走与标题栏压缩按钮相同的 compact RPC。成功即清空草稿；失败（如会话忙碌）保留草稿并提示；不能附带图片。正文中提及 `/compact` 的消息不受影响。

## Platforms and upgrade / 平台与升级

- Linux x64/arm64 and macOS Apple Silicon/Intel. Mac is ad-hoc signed, **not Developer ID signed or notarized**; no OS protection bypass is provided.
- Existing 0.3.7 installations can use the in-app path: **Settings → Check for updates**, download 0.3.8, save unsent drafts/queue contents, then explicitly confirm **Restart to apply**. `spi update` is the CLI alternative. This publication will not restart the current window for you; installation alone does not hot-update a running app.
- GitHub is the primary desktop update channel; no npm action is needed for that in-app update. The matching lightweight npm package remains the first-install path: `pi install npm:spi-agent-gui@0.3.8` after public npm verification.
- Remote protocol stays v2; saved pairings/profile/history are preserved. Immutable 0.3.7 assets are not replaced.
